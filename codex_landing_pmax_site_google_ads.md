# Codex Task — Landing Page PMax | Site + 3 Meses de Gestão de Google Ads

## Objetivo

Criar uma landing page específica para a campanha Performance Max da MintCode, focada em uma única oferta:

> **Contrate seu novo site e ganhe 3 meses de gestão de Google Ads.**

A página deve ser construída para **geração de leads qualificados**, com foco em empresas que precisam criar ou refazer um site e que também têm potencial para investir em Google Ads.

A landing page não deve parecer uma página promocional genérica ou excessivamente “barata”. A comunicação deve transmitir uma oferta de alto valor, combinando:

- criação de site profissional;
- performance;
- SEO técnico;
- mensuração;
- preparação para campanhas;
- gestão de Google Ads por 3 meses sem custo adicional.

---

# URL recomendada

Criar a página em:

```text
/site-google-ads/
```

URL final esperada:

```text
https://mintcode.com.br/site-google-ads/
```

Se a estrutura atual do projeto exigir outra convenção de rotas, manter o padrão existente do site, mas preservar uma URL curta e semanticamente clara.

---

# Regra principal da oferta

Nunca comunicar simplesmente:

> Google Ads grátis

Sempre utilizar:

> **3 meses de gestão de Google Ads grátis**

ou:

> **3 meses de gestão de Google Ads sem custo adicional**

Adicionar uma observação clara sempre que necessário:

> O investimento em mídia não está incluso e é pago diretamente pelo cliente ao Google.

---

# Direção visual

A nova página deve seguir **100% o design system atual da MintCode**.

Antes de desenvolver:

1. analisar a homepage atual;
2. analisar as páginas internas existentes;
3. reutilizar:
   - tipografia;
   - espaçamentos;
   - grid;
   - largura máxima dos containers;
   - botões;
   - border-radius;
   - sombras;
   - ícones;
   - cores;
   - header;
   - footer;
   - animações;
   - comportamento responsivo.

Não criar uma identidade visual paralela.

A landing precisa parecer uma página nativa da MintCode.


- fontes seguindo o padrão atual do projeto;
- manter o código limpo.

# Tracking

Preservar o Google Tag Manager já existente no projeto.

Não alterar IDs existentes.

Criar dataLayer events claros para:

## Clique principal

```javascript
dataLayer.push({
  event: 'lead_cta_click',
  page_type: 'site_google_ads'
});
```

## Início do formulário

```javascript
dataLayer.push({
  event: 'lead_form_start',
  page_type: 'site_google_ads'
});
```

## Formulário enviado com sucesso

```javascript
dataLayer.push({
  event: 'generate_lead',
  page_type: 'site_google_ads',
  lead_source: 'site_google_ads_offer'
});
```

## Clique no WhatsApp após conversão

```javascript
dataLayer.push({
  event: 'whatsapp_click',
  page_type: 'site_google_ads'
});
```

Nunca incluir no dataLayer:

- nome;
- telefone;
- e-mail;
- mensagem;
- qualquer PII.
